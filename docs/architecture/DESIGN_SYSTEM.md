# DESIGN SYSTEM SPECIFICATION

## 1. Visual Theme Tokens

- **Base Typography:** Inter, sans-serif (14px base font).
- **Color Palette:**
  - **Graphite 950 (`#0a0b0d`):** Primary canvas background.
  - **Graphite 900 (`#121418`):** Sidebar navigation and top header.
  - **Graphite 850 (`#181b21`):** Panel and card surfaces.
  - **Graphite 700 (`#2c323d`):** Subtle dividers and card borders.
  - **Futuristic Orange (`#ff5c00`):** Primary brand accent, active state pills, and status pulses.
  - **Emerald Green (`#10b981`):** Healthy operational state and $0 cost indicators.
  - **Signal Red (`#ef4444`):** Emergency halt buttons and critical kill-switch warnings.

---

## 2. Responsive Breakpoints

- **Mobile (390px):** Single-column grid, compact metric badges.
- **Tablet (768px):** Two-column card view.
- **Laptop / Desktop (1366px - 1920px):** Full multi-column dashboard with fixed sidebar and dynamic detail tabs.
