# RISK REGISTER & MITIGATION STRATEGY

| Risk ID    | Description                                                            | Severity | Probability | Mitigation Strategy                                                                                                                                                                 |
| ---------- | ---------------------------------------------------------------------- | -------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **RSK-01** | Host Machine 2GB VRAM limits running 7B/13B local LLMs                 | High     | High        | Local LLM heavy inference ke bajaye Cloud Free-tier (Gemini 2.5 Flash Free / Groq Free Llama-3) use ki jayegi. 1B-2B small models local fallback ke liye test honge.                |
| **RSK-02** | Docker daemon band hone par local PostgreSQL / Redis availability fail | Medium   | Medium      | Hybrid strategy: Docker start script provide ki jayegi. Alternative: Free-tier Serverless DB (Neon Postgres) + Free Redis (Upstash) seamless fallback ke tor par configured hain.   |
| **RSK-03** | npm PowerShell wrapper syntax error on host (`npm.ps1`)                | Low      | High        | PowerShell execution issues ko circumvent karne ke liye npm commands standard `cmd.exe /c npm` ya package scripts ke zariye trigger ki jayengi.                                     |
| **RSK-04** | Accidental financial charge from external APIs                         | Critical | Very Low    | $0 Zero-Cost hard interceptor. Credit cards bind nahi honge; free tier quota 90% par hard-abort ho jayega.                                                                          |
| **RSK-05** | Browser band hone par autonomous execution stop hona                   | High     | High        | Workers browser se completely detached hain. Node.js daemon (via PM2 / Windows Service / persistent background process) independent execute karega.                                 |
| **RSK-06** | Web scraping ya automated application submission par IP ban / CAPTCHA  | Medium   | Medium      | Playwright human-like typing delays, random user-agents, polite crawl rates. CAPTCHAs encounter hone par solve bypass nahi kiya jayega, task human approval gate par escalate hoga. |
| **RSK-07** | WhatsApp session logout / number flagging                              | Medium   | Low         | Low-frequency notification bridge. Spamming prohibited; strictly owner-facing critical security & approval alerts.                                                                  |
